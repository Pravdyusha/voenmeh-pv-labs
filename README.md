### Репозиторий содержит практические работы и курсовую по дисциплине **«Основы параллельных вычислений»**

**Язык:** C / C++

**Технологии:** OpenMP, POSIX Threads, CUDA, GCC Graphite

## Изученные темы

### Практическая работа №1 – Автоматическое распараллеливание программ

- Автоматическое распараллеливание с помощью GCC Graphite (`-floop-parallelize-all -ftree-parallelize-loops`)
- Реализация многоэтапной вычислительной программы (Generate → Map → Merge → Sort → Reduce)
- Сравнение последовательной и автоматически распараллеленной версий
- Измерение времени выполнения и ускорения

**Отчёт** → [practical-1.pdf](docs/practical-1.pdf)

### Практическая работа №2 – Использование библиотеки OpenMP

- Параллелизация всех этапов вычислений с помощью `#pragma omp parallel for`
- Использование различных типов расписаний (`schedule static`, `dynamic`, `guided`) и `chunk_size`
- Распараллеливание сортировки (`parallel sections`)
- Реализация прогресс-бара в отдельном потоке
- Сравнение производительности при разном количестве потоков

**Отчёт** → [practical-2.pdf](docs/practical-2.pdf)

### Практическая работа №3 – Использование POSIX Threads

- Полная переработка программы с OpenMP на POSIX Threads (`pthread_create`, `pthread_mutex`)
- Ручная реализация расписаний `schedule static`, `dynamic` и `guided`
- Синхронизация потоков и защита общих данных
- Сравнение с версией на OpenMP

**Отчёт** → [practical-3.pdf](docs/practical-3.pdf)

### Практическая работа №4 – Использование CUDA

- Перенос вычислений (Map и Merge этапы) на GPU
- Разработка kernel-функций и управление памятью (`cudaMalloc`, `cudaMemcpy`, `cudaFree`)
- Сравнение производительности CPU и GPU
- Расчёт доверительного интервала и профилирование

**Отчёт** → [practical-4.pdf](docs/practical-4.pdf)

### Курсовая работа – Применение параллельных вычислений при работе с базой данных списка адресов почты

- Проектирование и создание базы данных SQLite
- Разработка клиентского приложения на C++ для работы с БД
- Параллельная обработка данных из базы с использованием потоков
- Анализ производительности и эффективности параллельных вычислений

**Отчёт** → [coursework.pdf](docs/coursework.pdf)
